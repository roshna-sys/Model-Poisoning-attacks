This project presents a secure Federated Learning framework for credit-card fraud detection, focusing on the identification and mitigation of malicious model poisoning attacks in distributed learning environments. The framework simulates multiple clients participating in collaborative model training while preserving data privacy. It incorporates poisoning attack simulations, including sign-flipping,model scaling,label flipping and Gaussian-noise injection, along with a Random Forest-based anomaly detection mechanism to identify manipulated model updates. Additionally, trust-based evaluation, robust aggregation, and model recovery techniques are integrated to enhance the security, reliability, and resilience of Federated Learning systems.
